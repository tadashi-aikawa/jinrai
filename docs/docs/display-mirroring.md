# Display Mirroring

ホットキーを押すと、ディスプレイのミラーリングと拡張表示を切り替えます。会議室のプロジェクタなど外部ディスプレイをつないだとき、システム設定を開かずに切り替えられます。

切り替えたときは、今のモードを画面中央に短く表示します。

## 切り替えのルール

- 拡張表示のときに押すと、内蔵ディスプレイを残りのすべてのディスプレイへ映します
    - 内蔵ディスプレイがないときは、メインディスプレイを映します
- ミラーリング中のディスプレイが1台でもあるときに押すと、ミラーリングを解除して拡張表示に戻します
- ディスプレイが1台だけのときは何もしません

切り替えた構成は、システム設定で切り替えたときと同じくmacOSに記憶されます。次に同じディスプレイをつないだときは、その構成で始まります。

## 設定

[全設定](configuration.md)に、Display Mirroringの全項目、デフォルト値、各項目の説明を掲載しています。

`hotkey`を指定したときだけホットキーが登録されます。
`urlEvent.name`を指定すると、`jinrai://<名前>`のURLから切り替えられます。

```json
"displayMirroring": {
  "hotkey": {
    "modifiers": ["ctrl", "alt"],
    "key": "p"
  }
}
```

セクションを記述すると、メニューバーのJINRAIアイコンにも`ミラーリング ⇔ 拡張表示`が表示されます。ホットキーを忘れたときはここから切り替えられます。

!!! note
    ミラーリング中は、映している側のディスプレイだけが接続扱いになります。
    [プロファイル](profiles.md)の`displays`にミラー先のディスプレイだけを指定している場合、ミラーリング中はそのプロファイルが適用されません。
